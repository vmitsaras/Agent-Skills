# Visual Grammar Derivation Guide

Read this reference when a `brand-derived-visual-system` task needs detailed prompts for visual dimensions, application tests, system-source patterns, or anti-pattern diagnosis.

## Visual dimensions

### Composition

Describe relationships rather than a final grid:

```txt
Primary composition behavior:
Secondary behavior:
Use of asymmetry:
Use of whitespace:
Relationship between large and small elements:
How focal points are established:
How compositions may vary:
```

Possible behaviors include centered, offset, asymmetric, tightly framed, expansive, layered, sequential, modular, interrupted, edge-aligned, intentionally cropped, or a dominant focal area with a supporting field.

### Shape language

Derive recurring geometry from logo construction, product shape, material cuts, paths, diagrams, data relationships, or process markers.

For each shape, record:

```txt
Source:
Meaning:
Behavior:
Use cases:
Frequency:
Risk:
```

Remove geometry that merely looks branded without carrying meaning or organizing content.

### Framing

Define how the system treats boundaries: content inside frames, interrupted frames, open edges, image windows, cropping, overlapping planes, repeated margins, inset fields, or full bleed.

Explain why the behavior matters. Framing can create cross-format recognition through the relationship between content and space rather than literal decoration.

### Typography

Define roles before exact font families:

- Display: compact or expansive, restrained or expressive, oversized or moderate, dense or airy, stacked or linear, static or kinetic.
- Body: editorial, utilitarian, technical, conversational, compact, or generous.
- Hierarchy: scale, spacing, weight, position, contrast, and rhythm.
- Special language: labels, coordinates, measurements, annotations, serial numbers, captions, timestamps, or notation only when these derive from the project.

### Color

Begin with an existing palette when one exists. Separate:

- Identity color: preserves established recognition.
- Functional color: communicates interface state or information.
- Expressive color: changes atmosphere or emphasis.

Define background, accent, contrast, quiet, expressive, and image-interaction behavior. Do not invent palette complexity or exact values without need. Flag roles that may fail accessible contrast.

### Imagery

Specify:

```txt
Subject matter:
Distance and scale:
Crop and perspective:
Lighting and texture:
Context and human presence:
Documentation versus abstraction:
Movement:
Relationship to text:
```

When multiple image types are needed, give each a role. For example, documentary photography may provide proof, material macros atmosphere, and diagrams explanation. Do not group unrelated styles under one identity.

### Graphic devices

For frames, markers, rules, labels, borders, symbols, shapes, masks, arrows, diagrams, or texture, record:

```txt
Origin:
Meaning:
Requirement:
Typical intensity:
Useful contexts:
Distracting contexts:
```

A device must support meaning, organize content, or create recognition. Remove it otherwise.

### Texture and material

Use grain, paper, metal, glass, textile, print artifacts, wear, transparency, blur, or reflection only when project material supports them. Record source, purpose, intensity, application, and misuse. Texture is not a generic shortcut for "crafted" or "premium."

### Iconography and illustration

When relevant, specify whether the language is geometric or organic, literal or abstract, technical or expressive, outline or filled, and consistent or intentionally varied. Explain its relationship to the source. Do not invent a complete icon set.

## Motion prompts

Ask which verbs already exist in the concept, product, or process. Translate the strongest verbs into restrained motion principles.

```txt
Source:
Motion principle:
Meaning:
Possible uses:
Avoid:
Reduced-motion equivalent:
```

Example reasoning pattern:

```txt
mechanical fastening
-> rotate into alignment
-> assembly and precision
-> section transitions or state markers
-> never constant decorative spinning
```

Do not make every element perform the metaphor.

## Application tests

For each relevant context, answer:

```txt
Which principles remain?
Which variables change?
Which optional devices disappear?
What preserves recognition?
What accessibility or production constraint applies?
```

### Quiet-page test

Imagine a privacy policy, article, form, FAQ, account page, or long text page. If the project stops feeling recognizable without the dramatic hero treatment, the system is too shallow.

### High-expression test

Imagine a launch hero, campaign, featured project, or major announcement. Expression should amplify established principles rather than introduce a second identity.

### Density test

Test very sparse and very dense content. The system must neither require filler nor collapse under complexity.

### Format test

Test wide, portrait, square, small, and large formats. Adapt the behavior rather than merely scaling one composition.

### Mobile test

Prioritize meaning, hierarchy, recognition, and readability. Let expressive devices simplify or disappear.

### Accessibility test

Check contrast, reading order, legibility, zoom, reflow, reduced motion, touch, keyboard use, and cognitive load. Essential information must not depend on brand signature, color alone, or motion alone.

## System-source reasoning patterns

These are reasoning patterns, not style templates.

### Logo-derived

```txt
logo structure
-> spatial or framing relationship
-> compositions echo the relationship
-> recognition across varied content
```

Do not crop or manipulate a protected mark when brand rules prohibit it.

### Product-derived

```txt
distinctive product layers
-> overlapping planes
-> content and imagery use meaningful layers
-> system expresses depth and assembly
```

### Process-derived

```txt
raw material -> transformation -> finished state
-> layout and motion expose progression
-> system communicates craft and control
```

### Information-derived

```txt
complex inputs -> structured output
-> grammar moves from density toward order
-> system reinforces the product promise
```

### History-derived

```txt
archive typography and proportions
-> contemporary reinterpretation
-> continuity without nostalgic pastiche
```

### Location-derived

```txt
meaningful local structure
-> abstract spatial principle
-> repeated behavior across formats
```

Avoid reducing a culture or place to decorative stereotypes.

## Anti-patterns

### Trend package

Popular combinations such as muted editorial styling or neon glass effects are not a system without project-specific rationale.

### Logo wallpaper

Brand derivation does not require repeated logo display. Derive from proportions, negative space, construction, geometry, alignment, or rhythm when those are more useful.

### Metaphor overload

Connection does not require lines everywhere; rotation does not require everything to spin; layers do not require every element to overlap.

### Frozen template

Repeating the same hero, split layout, cards, and CTA creates a template. Let consistency come from principles that permit different compositions.

### Rulebook inflation

Remove obvious conventions, one-off treatments, hypothetical exceptions, microscopic decisions, and rules no one needs.

### Decorative derivation

Do not choose a shape aesthetically and later claim it was inspired by the product. The source must precede the rule.

### Everything mandatory

Optionality is necessary for flexible expression. If all ingredients appear everywhere, the system will become noisy and brittle.
