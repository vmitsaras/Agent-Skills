## Reporting rules

- Omit matrix rows and sections for which evidence is unavailable.
- Use exact artifact, page, section, state, or viewport evidence wherever possible.
- Do not disguise assumptions as observations.
- Do not use numerical scoring unless the user requests it.
- Keep priority corrections short and ordered by conceptual leverage.
- Include `Preserve` even when the verdict is weak; a useful review protects effective decisions.
- Recommend only the smallest set of specialist follow-ups needed to resolve remaining questions.
